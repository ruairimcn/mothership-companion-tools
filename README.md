# Mothership Companion Tools

Browser add-ons for [mothershipcompanion.com](https://mothershipcompanion.com/).

| Tool | What it does |
| --- | --- |
| [`folders-extension/`](folders-extension/) | Chrome extension that groups your characters, ships and maps into folders. |

## Install the folders extension

1. On this repo's page, click **Code → Download ZIP**, then unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the `folders-extension` folder.
4. Reload mothershipcompanion.com and sign in. Click the **FOLDERS** tab on the right edge or press **Alt+F**.

Updating from an earlier version? Click **Export** in the drawer first; see [`folders-extension/README.md`](folders-extension/README.md#update-to-a-new-version).

See [`folders-extension/README.md`](folders-extension/README.md) for details.
